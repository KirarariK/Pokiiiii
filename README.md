# PokéIdle (fan)

Jeu idle Pokémon dans le navigateur, inspiré de [poke-idle.fr](https://poke-idle.fr).

## Fonctionnalités

- Combat automatique sur les routes de Kanto
- Capture (Poké / Super / Hyper Ball) + auto-capture
- Équipe (6) + boîte PC
- Évolutions, montée de niveau, chromatiques (1/4096)
- Pokédex Gen 1 (151) avec sprites officiels (PokéAPI)
- Boutique, déblocage de zones, sauvegarde locale + progrès hors-ligne

## Lancer

```bash
npm start
# → http://localhost:4173
```

Ou simplement :

```bash
python3 -m http.server 4173
```
