# PokéIdle (fan)

Jeu idle Pokémon navigateur — **Pokédex national complet (1025 Pokémon, Gen I → IX)**.

## Fonctionnalités

- **1025 Pokémon** avec noms FR, stats, évolutions, sprites PokéAPI
- **Combat idle 1v1** (lead d’équipe vs sauvage), types, dégâts flottants
- Capture (Poké / Super / Hyper / Master Ball) + auto-capture
- **125+ zones** sur Kanto, Johto, Hoenn, Sinnoh, Unys, Kalos, Alola, Galar, Paldea
- Starters de **toutes les générations**
- Équipe (6) + PC, évolutions, boutique
- Pokédex filtrable par génération + recherche
- Sauvegarde locale + progrès hors-ligne

## Lancer

```bash
npm start
# → http://localhost:4173
```

Demo auto : [http://localhost:4173/?demo=1](http://localhost:4173/?demo=1)
